# Sky Ascent

## О проекте

**Sky Ascent** — это двухмерная пиксельная платформенная игра, разработанная на игровом движке **Godot** с использованием языка программирования **GDScript**.

Игрок управляет персонажем, который должен преодолевать платформы, избегать столкновений с монстрами, собирать монеты и проходить уровни возрастающей сложности.

---

## Геймплей

- Управление персонажем и прыжками по платформам  
- Препятствия и враги, которых необходимо избегать  
- Сбор монет для повышения результата  
- Постепенное увеличение сложности уровней  
- Переход между различными игровыми сценами

## Технологии

- Godot Engine
- GDScript
- Pixelorama (создание и редактирование пиксельной графики)
- Готовые ассеты с itch.io (с последующей переработкой и адаптацией)

---

## Особенности проекта

- Смешение готовых ассетов и собственных спрайтов  
- Визуальный стиль в пиксель-арт эстетике  
- Постепенно усложняющиеся уровни  
- Динамичный платформенный геймплей  
- Единый визуальный стиль благодаря переработке графики  

---

## Трудности и особенности разработки

В процессе разработки возникали сложности, связанные с:
- балансировкой сложности уровней  
- настройкой физики персонажа и прыжков  
- корректной обработкой столкновений  
- адаптацией сторонних ассетов под единый визуальный стиль  

Также важной частью работы стала переработка готовых графических ресурсов для создания более цельной и уникальной визуальной атмосферы игры.
